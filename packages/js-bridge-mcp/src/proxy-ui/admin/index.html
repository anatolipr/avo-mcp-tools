← MCP server proxies

Each proxy spawns/connects to an upstream MCP server and exposes its tools as a root connection, prefixed <slug>__ and merged into every MCP session's tools/list automatically — no join_channel needed; use describe_connection(slug) to inspect one by name. See /hub for a human-facing grouped view (with per-proxy /hub/<slug> scoping) to use with Human MCP Relay. An MCP client can also call describe_connection("admin") / use the admin__* tools directly for this same add/view/edit/pause/resume/restart/remove CRUD, no tab needed; this page mirrors it for a human via Cmd/Ctrl+Shift+A (Human MCP Relay).
